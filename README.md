# 物联网工程导论 · 复习资料

西北工业大学《物联网工程导论》课程的复习资料与课程资料合集。

> 本仓库所有资料完全免费发布，仅供学习交流使用。

## 简介

这份资料是《物联网工程导论》课程结束后、考试前为方便复习而整理的。主要内容摘自课本，摘抄依据为老师在最后一节课划的重点以及学长的笔记，部分习题为 DeepSeek 模型根据课本知识点整理的回答，汇总在一起方便考前背诵复习。

- **配套课本**：《物联网工程导论》吴功宜、吴英 编著，机械工业出版社，ISBN `978-7-111-76440-3`
- **授课教师**：李士宁
- **作者**：君 は 実 にバカだな（QQ 频道：启翔湖畔-西北工业大学）

## 内容说明

### 📖 物联网工程导论复习资料（`.md` / `.pdf`）

按章节整理的复习笔记，覆盖课程全部九章内容：

1. 智能物联网概论
2. 物品识别与 RFID 技术
3. 传感器与无线传感器网技术
4. 智能设备与嵌入式技术
5. 智能物联网通信与网络技术
6. 位置信息、位置服务与定位技术
7. 智能数据处理与大数据技术
8. 智能物联网安全技术
9. 智能物联网的应用领域

资料中标注了老师在最后一节课划定的考试重点、历年对应的课后习题出处，以及完整的大作业题目与考试题目安排。

> 💡 **2026 年考题回忆在「第十章 后记」里**，包括名词解释、简述题与论述题的完整题目列表。

### 📝 物联网大作业（`.docx`）

本课程自 2026 年起新增课程大作业，要求以 **电动汽车** 为题进行智能物联网总体架构设计，锻炼「端-边-网-云-用」整体架构的把握能力。

### 📊 PPT 课件

`PPT/` 目录下包含两套课件：

- `第1章-概论.pdf` ~ `第9章-物联网应用.pdf`
- `1-物联网工程导论（第2版）第1章 概论-1.pdf` ~ `9-物联网工程导论（第2版）第9章 物联网应用.pdf`

老师讲课仅依据其 PPT，不依赖课本，考前复习时建议配合课件一起看（部分考点仅出现在 PPT 中，课本上并没有）。
